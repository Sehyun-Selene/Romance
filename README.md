# 일일산수

## 프로젝트 소개
사용자의 일정과 취향을 분석하여 빈 시간에 어울리는 낭만 미션을 추천하는 리버스 투두리스트입니다.

## 주요 기능
- 취향 선택
- 일정 입력
- 빈 시간 분석
- 낭만 미션 추천
- 미션 완료 체크 및 낭만 미션 수행 시 토끼 캐릭터가 점프를 하며 산을 넘음
- 개인화된 산수화 컨셉의 투두리스트 엽서집 생성

## 웹 컨셉 
바쁜 나날 속에서도 하루의 여백을 낭만으로 채우는 투두리스트 웹입니다. 판소리 소설 수궁가의 토끼처럼, 때로는 분주하게 오늘의 할 일을 해치우고, 때로는 소소한 낭만 미션으로 일상의 여유를 찾을 수 있기를 바랍니다.
